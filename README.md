# Pro Design Studio

منصة تصميم عربية احترافية مبنية على React + TypeScript + Vite، مع محرك تصميم تفاعلي، مكتبة قوالب، حفظ محلي، وتصدير PNG/JPEG/PDF.

## المميزات

- واجهة عربية RTL كاملة
- محرر تصميم تفاعلي باستخدام React Konva
- مكتبة قوالب قابلة للبحث والتصفية
- حفظ المشاريع محليًا عبر IndexedDB
- دعم التراجع/الإعادة، النسخ، الحذف، والخصائص
- تصدير PNG و JPEG و PDF
- جاهز للتوسع مع ميزات الذكاء الاصطناعي والاتصال بالخادم لاحقًا

## التثبيت

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## الاختبارات

```bash
npm run test
```

## البيئة

انسخ ملف `.env.example` إلى `.env` وقم بتعديل القيم عند ربط خدمات خارجية.

## ملاحظات

- لا يتم تخزين أي مفاتيح سرية داخل الكود.
- ميزات الذكاء الاصطناعي تُعرَض كواجهة جاهزة للاتصال بالخدمات الخارجية فقط عند توفر API فعلي.
- الحسابات والأتمتة السحابية تحتاج إلى خادم مستقل ومصادقة آمنة.

## النشر

يمكن نشر التطبيق على أي استضافة تدعم React (Vercel / Netlify / GitHub Pages) باستخدام إعدادات Vite الحالية.
